# 🚀 Quick Start Guide

## Get Your Roadmap in 3 Steps!

### Step 1: Navigate to the directory
```bash
cd cybersecurity-roadmap
```

### Step 2: Install dependencies
```bash
pip install -r requirements.txt
```

### Step 3: Generate your PDF
```bash
python roadmap_generator.py
```

**Done!** Your PDF is ready at: `output/cybersecurity_roadmap.pdf`

---

## 📖 What You'll Get

A 39-page professional PDF containing:

- **13 Learning Stages** from Absolute Zero to Expert
- **12 Certifications** including OSCP, OSWE, OSEP, and more
- **40+ YouTube Channels** with QR codes for quick access
- **30+ Practice Labs** organized by difficulty
- **70+ Tools** categorized by domain
- **Clickable Links** for easy navigation
- **Easter Egg** 🎵 (hint: scan the last QR code!)

## 🆘 Troubleshooting

### PDF is blank?
```bash
# Verify data files exist
ls -l data/

# Regenerate
python roadmap_generator.py
```

### Import errors?
```bash
# Upgrade dependencies
pip install --upgrade -r requirements.txt
```
